

# Assistive Communication Using Sign Language Recognition

## 📌 Project Overview

**Assistive Communication Using Sign Language Recognition** is a software-based project designed to bridge the communication gap between individuals with speech impairments and the general community. The application uses computer vision, image processing, and machine learning techniques to recognize hand gestures and translate them into readable text and audible speech.

## 🎯 Objectives

* Recognize sign language gestures using camera input.

* Convert recognized gestures into readable text.

* Provide audio output to facilitate communication.

* Promote accessible and inclusive communication through technology.

## 🛠️ Technologies & Libraries

* **Python** — Core programming language.

* **OpenCV** — Image processing and camera input.

* **NumPy** — Numerical computations and data processing.

* **TensorFlow** — Machine learning and gesture classification.

## ✨ Key Features

* Camera-based hand gesture recognition.

* Text output for recognized gestures.

* Speech output for accessible communication.

* User-friendly graphical interface.

## 🔬 Research & User-Centered Design

Field visits to special education schools in Quetta helped identify user needs and practical challenges, informing the project's design.
